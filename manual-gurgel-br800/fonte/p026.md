#### Tabela de Localização de Falhas

<table class="grid falhas"><colgroup><col style="width:27%"><col></colgroup>
<thead><tr><th style="text-align:left">Falhas</th><th>Causa Provável</th></tr></thead><tbody>
<tr><td>o motor funciona mas pára</td><td><p>Se o motor funciona durante alguns segundos, parando em seguida, examinar:<br>- o sistema de combustível<br>- o sistema de ignição</p></td></tr>
<tr><td>o motor funciona mas falha</td><td><p>Determinar primeiramente se a falha é constante ou periódica, e a que rotação a falha ocorre, fazendo o motor funcionar, sob carga, a diversas rotações.</p></td></tr>
<tr><td>falha constantemente em todas as rotações</td><td><p>Isolar a falha, fazendo o motor funcionar com um cilindro, sem ignição. Isto se consegue fazendo o motor funcionar após retirar o cabo de uma vela por vez, até que os dois cilindros tenham sido examinados.</p><p>Ligar à massa o cabo de vela que foi desligado.</p><p>Se a rotação varia, quando se faz curto-circuito no cabo de vela de um dos cilindros, este cilindro está sem problemas.</p><p>Se não houver variações no funcionamento do motor, ao retirar o cabo, a falha é ocasionada pelo cilindro correspondente a este cabo.</p><p>Examinar:<br>- o sistema de ignição<br>- a pressão de compressão</p></td></tr>
<tr><td>falha periodicamente em todas as rotações</td><td><p>Não se podendo isolar a falha em um dos cilindros</p><p>Examinar:<br>- o sistema de ignição<br>- o sistema de combustível<br>- a pressão de compressão<br>- o sistema de escapamento para verificar se há restrições<br>- o sistema de arrefecimento, para verificar se há alguma avaria que impeça o motor de chegar à temperatura normal de funcionamento</p></td></tr>
<tr><td>falha somente em marcha lenta</td><td><p>Examinar:<br>- o sistema de combustível<br>- o sistema de ignição<br>- o ajuste da folga das válvulas<br>- a pressão de compressão, para verificar se é baixa</p></td></tr>
<tr><td>falha somente em alta rotação</td><td><p>Examinar:<br>- sistema de ignição<br>- sistema de combustível<br>- o sistema de arrefecimento, para verificar se há superaquecimento</p></td></tr>
<tr><td>marcha lenta irregular</td><td><p>Examinar:<br>- folga das válvulas<br>- vazamentos nos coletores de admissão<br>- sistema de ignição<br>- sistema de combustível<br>- parafusos de montagem do motor frouxos<br>- alçamento dos tuchos das válvulas</p></td></tr>
</tbody></table>
